## Leader gripper hold (motorized Star leader haptic wall)

- User authorized a haptic layer on top of the soft squeeze limit: on a MOTORIZED Star Arm 102 leader, hold the leader gripper servo rigid while the operator over-squeezes the Metal follower, so they feel the wall instead of stalling the follower. Built on branch feat/gripper-leader-hold, stacked on codex/metal-gripper-soft-limit.
- Spike already done on the real purple arm (reference_fashionstar_servo_hold_gotcha): stiff hold via set_angle(id, target, multi_turn=True, interval_ms~150) re-asserted a few Hz, read frame must match write frame or the readback is faked.
- makermodslab/gripper_leader_hold.py: a monitoring/holding/probing state machine. Engage when the operator's commanded gripper.pos is >= gap_deg below the follower's present gripper.pos for a debounce window. Hold re-asserts at ~7 Hz. Every ~0.4 s: unlock ~0.1 s and watch the operator's true hand; opening the handle >= 3 deg releases, otherwise re-engage. Also releases when the follower catches up (hysteresis) and on any exception. install_gripper_leader_hold wraps robot.send_action AFTER the soft limiter; a rate-limited DamiaoMotorsBus Present_Position read supplies the follower position; the follower's startup sync suppresses engagement. Single-arm Metal only; bimanual raises.
- Robot Settings expose nullable gripper_leader_hold_gap_deg (default off, finite positive), capability-gated on the new supports_gripper_leader_hold flag (Metal only), EN/ZH UI, next local teleop/record session. Persistence validates before writes, null clears, omitted preserves, arm-family switch clears; legacy named starts inherit the saved gap. Teleop and record cleanup call controller.release() first because the arm family's leader torque release is a no-op on the motorless Star leader.
